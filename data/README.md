# 示例素材来源与准备方式

来源：[Oxford Visual Geometry Group — 17 Category Flower Dataset](https://www.robots.ox.ac.uk/~vgg/data/flowers/17/)。完整数据集包含 17 类花朵，每类 80 张图片。

本项目只使用一个小型入门样本：

- `tiles/`：每类选择 6 张，共 102 张；中心裁成正方形，再缩放到 256×256，以 JPEG 保存。
- `target.jpg`：从 `image_0001.jpg` 缩放到 200×150。该原图未放入 `tiles/`，避免直接拿目标原图匹配自身。
- 保留素材文件原始编号，例如 `image_0002.jpg`，便于追溯。

采样编号：对于第 k 类（k 从 0 到 16），选取 `80*k+2+13*j` 的图片，其中 j 从 0 到 5。例如第一类为 0002、0015、0028、0041、0054、0067。小样本用于演示运行流程，颜色覆盖有限，输出可能大量重复使用相同的花朵。

照片版权和使用条件属于原数据提供方；代码的 MIT 许可不适用于这些照片。研究中使用本数据集请按官网说明引用数据集论文。
